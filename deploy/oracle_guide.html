פתח חשבון Oracle Cloud

לחץ על הכפתור ופתח חשבון חינמי. דורש כרטיס אשראי לאימות בלבד — לא יגבו ממך כלום.

👉 פתח חשבון Oracle Cloud חינמי
⚠️ בחר Region: US East (Ashburn) — הכי קרוב לשרתי Alpaca
✅ אחרי הרשמה תקבל אימייל, לחץ על הקישור ותוכנס ל-Console
2

צור VM חינמי

בתוך ה-Console של Oracle, לחץ על "Create a VM instance"

Name
trading-agent
Image
Ubuntu 22.04
Shape
VM.Standard.A1.Flex
OCPUs
1 CPU
Memory
6 GB RAM

📌 לבחירת Shape: לחץ "Change Shape" → בחר Ampere → VM.Standard.A1.Flex

⚠️ SSH Keys: לחץ "Generate a key pair" ↓ שמור את שני הקבצים!

לחץ Create ↓ המתן דקה ↓ העתק את ה-Public IP Address

3

העלה את הקוד ל-VM

פתח Terminal על ה-Mac שלך והרץ:

# החלף YOUR_VM_IP בכתובת ה-IP שקיבלת VM_IP="YOUR_VM_IP" # העלה את כל הפרויקט scp -i ~/Downloads/ssh-key-*.key -r ~/trading-agent ubuntu@$VM_IP:~/trading-agent # התחבר ל-VM ssh -i ~/Downloads/ssh-key-*.key ubuntu@$VM_IP
4

הגדר API Keys על ה-VM

אחרי שהתחברת ל-VM, הרץ:

cd ~/trading-agent cp .env.example .env nano .env

בקובץ ה-.env, מלא את הפרטים:

ALPACA_API_KEY=your_key_here ALPACA_SECRET_KEY=your_secret_here TELEGRAM_BOT_TOKEN=your_token_here TELEGRAM_CHAT_ID=1766412347

שמור: Ctrl+O → Enter → Ctrl+X

5

הרץ סקריפט ההתקנה

פקודה אחת שמתקינה הכל ומגדירה תזמון אוטומטי:

chmod +x deploy/setup_oracle.sh bash deploy/setup_oracle.sh
✅ זה מתקין Python, dependencies, ומגדיר את הסוכן לעלות ולרדת אוטומטית לפי שעות מסחר
6

פתח גישה ל-Dashboard

כדי לראות את הדשבורד מהדפדפן:

באתר Oracle Cloud: Networking → Virtual Cloud Networks → VCN שלך → Security List → Add Ingress Rule:

Source
0.0.0.0/0
Port
5555
Protocol
TCP

על ה-VM:

sudo iptables -I INPUT -p tcp --dport 5555 -j ACCEPT sudo apt-get install -y iptables-persistent sudo netfilter-persistent save
✅ הדשבורד יהיה נגיש בכתובת: http://YOUR_VM_IP:5555
7

הפעל ובדוק

sudo systemctl start trading-agent sudo systemctl start trading-dashboard sudo systemctl status trading-agent tail -f ~/trading-agent/logs/agent.log
✅ הסוכן רץ! מעכשיו הוא יעלה לבד כל יום ב-09:25 ET ויכבה ב-16:05 ET
