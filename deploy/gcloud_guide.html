3

העלה את הקוד ל-VM

בתוך ה-Terminal שנפתח בדפדפן, הרץ:

sudo apt-get install -y git rsync

עכשיו פתח Terminal על ה-Mac שלך והרץ (מחליף את כל ה-Oracle בקוד):

# קבל את שם הפרויקט וה-VM שלך מהאתר ZONE="us-east1-b" # או כל zone שבחרת INSTANCE="trading-agent" # העלה את הקוד gcloud compute scp --recurse ~/trading-agent $INSTANCE:~/trading-agent --zone=$ZONE # התחבר gcloud compute ssh $INSTANCE --zone=$ZONE
⚠️ אם אין לך gcloud CLI — אפשר גם להעלות ישירות מהדפדפן: לחץ על שם ה-VM ← Upload File
4

הגדר API Keys

בתוך ה-Terminal (בדפדפן או Terminal Mac):

cd ~/trading-agent cp .env.example .env nano .env

מלא את הפרטים:

ALPACA_API_KEY=your_key_here ALPACA_SECRET_KEY=your_secret_here TELEGRAM_BOT_TOKEN=your_token_here TELEGRAM_CHAT_ID=1766412347

שמור: Ctrl+O → Enter → Ctrl+X

5

הרץ סקריפט ההתקנה

פקודה אחת שמתקינה הכל:

chmod +x deploy/setup_oracle.sh bash deploy/setup_oracle.sh
✅ מתקין Python, dependencies, ומגדיר auto-start לפי שעות מסחר
6

פתח גישה ל-Dashboard (פורט 5555)

באתר Google Cloud: VPC Network → Firewall → Create Firewall Rule:

Name
allow-dashboard
Direction
Ingress
Source
0.0.0.0/0
Protocol/Port
TCP: 5555

על ה-VM:

sudo ufw allow 5555/tcp sudo ufw --force enable
✅ הדשבורד יהיה נגיש בכתובת: http://YOUR_EXTERNAL_IP:5555
